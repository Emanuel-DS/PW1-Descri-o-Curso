Introdução DS 2 Ano

A matéria de Desenvolvimento de Sistemas (DS) é, de muitas formas, o "coração" do curso de tecnologia. Se a Programação Web (PW) constrói a vitrine e o Banco de Dados (BD) funciona como a memória, o Desenvolvimento de Sistemas é o cérebro e a engenharia por trás de tudo. Em resumo, DS é o estudo de como planejar, criar, testar e manter softwares e aplicativos de forma profissional e eficiente. Não se trata apenas de digitar códigos aleatórios, mas de resolver problemas reais criando programas que funcionem bem, não travem e sejam fáceis de atualizar no futuro.

Pra que serve na prática?

A matéria de DS serve para te ensinar a construir soluções completas. Enquanto a PW foca muito no navegador de internet, o Desenvolvimento de Sistemas abrange um universo maior. Com os conhecimentos de DS, você pode criar: Sistemas Empresariais (ERPs): Programas de computador usados por lojas, hospitais ou bancos para controlar estoque, folha de pagamento e caixa. Aplicativos Mobile: Apps para Android e iOS que você usa no celular. Softwares Desktop: Programas que você instala no Windows ou no Mac, como o pacote Office, editores de vídeo ou sistemas de ponto de venda. Integrações (Back-end robusto): Criar a lógica que conecta o aplicativo do seu celular com o banco de dados que está lá do outro lado do mundo.

O que você aprende nessa matéria?

O foco de DS é te transformar em um programador completo, capaz de pensar na arquitetura do projeto do início ao fim. Os principais tópicos que você vai encontrar são: Lógica de Programação e Algoritmos: A base de tudo. É onde você aprende a pensar como um computador e a criar um passo a passo para resolver problemas. Linguagens de Programação Base: Geralmente, você vai aprender linguagens robustas e muito usadas no mercado corporativo, como Java, C#, Python ou C++. Programação Orientada a Objetos (POO): Uma forma avançada e organizada de escrever códigos, onde você cria "moldes" (classes) para representar coisas do mundo real (como um "Cliente" ou um "Produto"). Engenharia de Software: Você aprende o ciclo de vida de um software. Isso inclui como levantar os requisitos com o cliente, planejar o projeto, escrever o código e, muito importante, como testar o sistema para encontrar erros (bugs) antes que ele seja lançado.
