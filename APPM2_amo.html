Introdução Aplicativo Mobile

A matéria de Aplicativos Mobile I é a sua porta de entrada para o ecossistema dos smartphones. Se em Programação Web (PW) você aprende a criar para os navegadores, aqui o foco é 100% no que as pessoas baixam nas lojas de aplicativos (Google Play Store e Apple App Store) e instalam direto na telinha do celular. Sendo a primeira parte da disciplina (nível "I"), ela serve para te tirar do zero absoluto e te mostrar a anatomia básica de um aplicativo, ensinando como adaptar o desenvolvimento de sistemas para telas menores, toques com os dedos (touch) e os recursos do próprio aparelho.

Para que serve na prática?

Na prática, essa matéria serve para te ensinar a transformar uma ideia em um aplicativo real e instalável. O que você aprende nessa matéria?

Como é o primeiro contato, o objetivo não é criar um "novo Instagram" logo de cara, mas construir uma base sólida. Os tópicos principais que você vai ver costumam ser: Design de Interface (UI) para Telas Pequenas: Como organizar botões, listas, imagens e textos para que funcionem bem em diferentes tamanhos de tela (de um celular pequeno até um tablet). Interatividade e Eventos: Você aprende a programar o que acontece quando o usuário toca, desliza (swipe) ou segura o dedo em um botão na tela. Uso de Emuladores: Como usar programas no computador que simulam um celular real, para que você possa testar o aplicativo sem precisar instalar no seu próprio aparelho toda vez. O Ciclo de Vida do App: Entender o que acontece com o código quando o usuário abre o app, quando ele minimiza para responder uma mensagem no WhatsApp, e quando ele volta para o app.

Ferramentas Comuns

O que você vai usar depende da abordagem da sua escola, mas geralmente começa por um destes caminhos: Programação Visual (Iniciantes): Ferramentas como o MIT App Inventor, onde você cria a lógica arrastando blocos (ótimo para pegar o raciocínio rápido). Desenvolvimento Nativo (Android): Usar o Android Studio com linguagens como Java ou Kotlin para criar apps oficiais para o sistema do Google. Desenvolvimento Híbrido/Cross-platform: Usar tecnologias web que você aprendeu em PW para criar apps (como React Native), onde um único código gera um app tanto para Android quanto para iPhone.
